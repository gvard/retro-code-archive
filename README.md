# 🏛️ retro-code-archive

[English](#english) | [Русский](#русский)

---

## English

A curated collection of legacy applications from the mid-to-late 1990s and 2000s, originally developed across various programming languages and IDEs primarily for educational purposes and personal enjoyment.

In 2026, the entire archive was fully refactored, modernized, and ported to contemporary development environments. All known legacy bugs, hardware conflicts, and unfinished features have been mostly resolved, while unrealized concepts and unfulfilled ideas from decades ago have finally been brought to completion.

### Key Highlights
* Ported to stable, modern compilers (e.g., C++ Builder 10.4 Sydney / RAD Studio).
* Resolved historical division-by-zero crashes, boundary errors, floating-point exceptions, and related computational anomalies.
* Optimized compilation settings to produce lightweight, standalone executables with zero external dependencies.

## Русский

Коллекция архивного программного обеспечения середины-конца 1990-х и 2000-х годов. Все проекты изначально создавались на различных языках и в средах программирования, преимущественно в учебных целях и ради удовольствия.

В 2026 году весь архив был полностью переработан и адаптирован под современные среды разработки. Устранены все известные баги и логические недоработки, реализованы замороженные десятилетия назад идеи.

### Основные особенности
* Код успешно адаптирован под актуальные компиляторы (включая C++ Builder 10.4 Sydney / RAD Studio).
* Исправлены классические ошибки падения при делении на ноль, падения математического сопроцессора и т.д.
* Настройки релизов оптимизированы для сборки независимых (Standalone) исполняемых файлов, которые запускаются без установки дополнительных библиотек.
